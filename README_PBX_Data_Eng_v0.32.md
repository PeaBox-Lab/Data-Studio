# PBX Data Eng v0.32 - Visual Lineage Studio

v0.32 turns lineage into a visual, navigable governance experience.

## New
- Interactive lineage graph rendered inside the PySide6 desktop application with Matplotlib.
- Color-coded asset types: datasets, pipelines, dashboards, models, APIs and jobs.
- Directed arrows and relationship labels for downstream dependencies.
- Focus-asset selector and selected-node highlighting.
- Asset and relationship totals on the lineage canvas.
- Data Lineage now opens the visual studio directly.
- Dedicated Lineage Visualization action in Ctrl+K.
- Restores and hardens lineage builder/impact methods in the v0.32 source.

## Retained
Everything through v0.31 remains retained: data contracts, validation rules, cleaning/remediation, profiling, health/recovery, SQL, pipelines, semantic models, dashboards, analytics, AutoML, explainability, monitoring, deployment, jobs and headless execution.
