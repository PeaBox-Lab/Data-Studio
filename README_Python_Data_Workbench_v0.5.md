# Python Data Workbench v0.5 - Analytics Platform

v0.5 evolves the desktop workbench toward a general-purpose Python-backed data analytics platform.

## New analytics layer
- Dedicated Analytics workspace
- Executive Dashboard backed by the live active DataFrame
- KPI cards for rows, columns, missing data, duplicates, and numeric averages
- Automatic numeric profile table
- Automatic distribution chart
- Generated executive analytical summary
- Segment analysis with count, total, mean, median and contribution share
- Trend analysis with daily/weekly/monthly/quarterly/yearly resampling, growth rate, and 3-period moving average
- Pareto analysis with contribution and cumulative percentage
- Cohort/cross-tab analysis for two business dimensions

## Platform capabilities retained
- Multiple datasets per project
- `.pdw` project persistence
- Visual cleaning and transformations
- Statistics and scientific processing
- Machine learning, model comparison and batch prediction
- Chart builder and chart export
- Engineering analysis, optimization, signal processing and simulation
- Shared Python Lab
- Python scripts and workflow export

## Run on Windows
Extract the release and double-click `run_workbench_v0.5.bat`.

## Notes
The current UI is designed as a desktop analytics workbench. v0.6 should focus on reusable dashboards, drag/drop dashboard composition, SQL/DuckDB analytics, larger-than-memory datasets, semantic metrics, and a safer ZIP/JSON/Parquet project format.
