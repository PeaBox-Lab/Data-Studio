# PBX Data Eng v0.26 - Workspace Health & Recovery

v0.26 continues the UX-first roadmap by adding an operational health and recovery layer without removing the v0.25 Smart Workspace capabilities.

## New
- Workspace Health report with a 0-100 readiness score.
- Checks for data completeness, duplicates, reusable pipelines, dashboards, model lifecycle, monitoring, automation and saved-project recovery state.
- Recovery guidance for project saves, reusable transformations, model monitoring and destructive-change protection.
- Workspace Health available from Home and Ctrl+K Quick Actions.
- Smart recommendation state is now persisted with v0.26 projects.

## Retained
All v0.25 capabilities remain, including data editing, pandas/DuckDB/PySpark engines, SQL, pipelines, semantic modelling, dashboards, statistics, engineering analytics, AutoML, explainability, model monitoring, REST deployment, jobs and headless orchestration.
