# PBX Data Eng v0.25 - Smart Workspace

v0.25 builds on the v0.24 personalized workspace with context-aware guidance while retaining the complete analytics platform.

## New
- Smart Recommendations evaluates the active dataset and project state and proposes next-best actions.
- Recommendations cover missing data, duplicates, reusable pipelines, dashboards, AutoML, model monitoring and automation.
- Smart Recommendations is accessible from Home, Ctrl+K Quick Actions and normal tool routing.
- Workspace preferences and recent actions are persisted in newly saved v0.25 projects.
- Project payload version updated to 0.25.

## Retained
Data editing, pandas/DuckDB/PySpark engines, SQL, pipelines, semantic modelling, dashboards, statistics, engineering analytics, AutoML, explainability, monitoring/drift, REST deployment, scheduler/jobs, and headless orchestration remain retained from v0.24.
