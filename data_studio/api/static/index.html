Quick help

How Data Studio works

Data Studio is a local-first analytics workbench. Everything is stored in a folder you choose, and opening a project never executes code.

Typical workflow

  • Data — import CSV, Excel, JSON, Parquet or DuckDB.
  • Prepare — add cleaning steps and preview the result.
  • Analyze — run typed descriptive, inferential or time-series analyses.
  • Saved — keep results, refresh on a schedule and download reports.
  • Export — write cleaned data as Parquet, CSV, JSON or Excel.

Analysis categories

  • Descriptive — summaries, distributions, frequency tables and cross-tabs.
  • Inference — hypothesis tests, confidence intervals and effect sizes.
  • Time series — trend, seasonality, ACF/PACF and ARIMA forecasts.

Freshness and schedules

  • Fresh — inputs and app version match the saved fingerprint.
  • Stale — data or pipeline changed; refresh to update.
  • Missing — the dataset is no longer in the project.
  • Schedules: manual, on project open, hourly or daily.

Keyboard shortcuts

  • ? — open this help.
  • / — focus the analysis search while in Analyze.
  • Esc — close a dialog or tooltip.

Data safety

  • No pickle: projects are JSON, Parquet and JSON only.
  • Dataset paths stay inside the project folder.
  • Reports are self-contained HTML with no scripts.
  • Refreshes are explicit; there is no background daemon.

Tips

  • Hover or focus any ? for contextual help.
  • Analyse the pipeline output to match the cleaned preview.
  • Save an analysis to compare fresh results over time.
