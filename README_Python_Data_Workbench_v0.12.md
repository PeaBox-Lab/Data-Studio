# Python Data Workbench v0.12 - Advanced Business Analytics

## New analytics packs

### HR / Workforce
- Headcount and distinct employee count
- Join-date-based tenure calculation
- Recorded exits and indicative attrition ratio
- Compensation average and total payroll
- Department or status-level analysis

### Finance
- Budget versus actual
- Absolute and percentage variance
- Revenue, cost, profit and margin
- Category or period summaries

### Sales
- Revenue and quantity analysis
- Customer, product or regional grouping
- Distinct customer and product counts
- Transaction averages and totals

### Operations
- Output and capacity
- Utilization percentage
- Defect rate
- Cycle-time analysis
- Process or machine summaries

## Reusable design
- Guided field mapper lets users map arbitrary source columns to standard analytical roles
- Pack outputs are saved as project datasets
- Analytical narratives are generated in Python Lab
- Pack results can create Dashboard Studio dashboards automatically
- Pack metadata persists with `.pdw` projects

## Retained
All capabilities from v0.1-v0.11 remain included.

## Run
Extract and run `run_workbench_v0.12.bat`.
