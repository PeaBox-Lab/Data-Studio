# Python Data Workbench v0.23 - Productivity Workspace

v0.23 builds on the validated v0.22 Guided Workspace and focuses on everyday analyst productivity.

## New
- Workspace Overview showing active data health, project assets and a recommended next step.
- Recent Actions list so common work can be repeated quickly.
- Focus Mode to reduce desktop clutter while working on data, charts or code.
- New Home cards for Recent Actions, Workspace Overview and Focus Mode.
- Quick Actions expanded with the new productivity commands.
- Existing task navigation, Ctrl+K palette and v0.21/v0.22 automation capabilities retained.

## Navigation
Home → Data → Transform → Analyze → Visualize → Model → Automate → Advanced.
