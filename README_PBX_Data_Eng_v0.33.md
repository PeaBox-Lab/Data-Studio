# PBX Data Eng v0.33 - Contract Test Automation & Lineage Export

## New
- Contract test suites generated from governed v0.30 data contracts.
- Automated PASS/FAILED runs using blocking ERROR/FAIL findings.
- Run history with timestamps, totals, blocking counts and detailed findings.
- JSON contract-test report export for CI/CD evidence and audit trails.
- Persistent contract suites and run history inside project files.
- Lineage export to high-resolution PNG and vector SVG.
- Reusable lineage renderer shared by export workflows.
- Ctrl+K actions for Contract Test Automation and Export Lineage.

## Retained
All functionality through v0.32 remains retained, including visual lineage, impact analysis, governed contracts, validation rules, cleaning, profiling, analytics, ML, monitoring, deployment, scheduling and headless execution.
