# PBX Data Eng v0.31 - Data Lineage & Impact Studio

v0.31 adds lineage and downstream impact analysis to the governance layer introduced in v0.30.

## New in v0.31
- Lineage graph model covering datasets, pipelines, dashboards, registered models, API deployments and scheduled jobs.
- Relationship inventory for dataset inputs, dashboard visualizations, model training and model serving.
- Downstream impact traversal from the active dataset.
- Impact review guidance before destructive schema changes.
- Data Lineage integrated with Ctrl+K and standard tool routing.
- Designed to work alongside v0.30 Data Contracts for governed schema evolution.

## Retained
All capabilities through v0.30 remain retained, including data contracts/governance, validation rules, cleaning/remediation, data-quality profiling, Workspace Health, Smart Workspace, SQL, pipelines, dashboards, statistics, engineering analytics, AutoML, explainability, model monitoring, REST deployment, scheduler/jobs and headless execution.
