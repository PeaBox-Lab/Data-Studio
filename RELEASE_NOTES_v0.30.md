# PBX Data Eng v0.30 Release Notes

v0.30 establishes a governed data-interface layer. Teams can generate a draft contract from a known-good dataset and validate later datasets for schema, type, nullability and learned-rule conformance before downstream analytics or ML.

Recommended use: establish a trusted baseline, review inferred rules, assign ownership, version the contract, then use conformance findings as a quality gate for production pipelines.
