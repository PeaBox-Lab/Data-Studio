# Python Data Workbench v0.22 - Guided Workspace

## User-friendly information architecture
Home, Data, Transform, Analyze, Visualize, Model, Automate and Advanced replace the earlier long list of specialist top-level tabs.

## New usability features
- Getting Started journey chooser
- Global Ctrl+K Quick Actions search
- Favorites-first common actions
- Ctrl+I import, Ctrl+E export, Ctrl+S save, Ctrl+O open and Ctrl+Z undo
- Wider project panel and clearer workflow guidance
- SQL, DuckDB, Spark and Python consolidated under Advanced

## Retained capabilities
The cumulative analytics, pipelines, dashboards, semantic model, AutoML, ML lifecycle, monitoring, REST deployment, scheduler and v0.21 headless orchestrator are retained.
