# PBX Data Eng v0.32 User Guide

Open Ctrl+K and select **Lineage visualization** or **Data lineage**.

The canvas groups assets by type. Arrows show downstream relationships. Use **Focus asset** to highlight a specific dataset, pipeline, dashboard, model, API or scheduled job.

Before changing a dataset schema, inspect the map to identify downstream assets, review the v0.30 data contract, then retest the affected assets after the change.
