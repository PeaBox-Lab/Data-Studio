# Python Data Workbench v0.11 - Dashboard Designer 2.0

## New in v0.11
- Persistent multi-visual dashboard definitions
- KPI tiles using semantic measures, SUM or AVG numeric measures
- Bar, line, scatter, histogram and box chart tiles
- Detail-table tiles with user-selected columns
- Dashboard layout editor with tile ordering, enable/disable and deletion
- Dashboard slicers using dataset columns
- Dashboard context recalculates KPI, chart and table tiles
- Dashboard JSON import/export
- Dashboard definitions persist inside project files
- Scrollable visual canvas suitable for progressively richer dashboard layouts

## Retained platform
All capabilities through v0.10 remain: semantic model, reproducible pipelines, lazy DuckDB CSV/Parquet, SQL, pandas/DuckDB/optional PySpark engines, ML, statistics, engineering, business analytics, Python Lab and project persistence.

## Run
Extract the ZIP and double-click `run_workbench_v0.11.bat`.
