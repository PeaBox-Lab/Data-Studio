# Data Studio v0.38 Feature Inventory

v0.38 retains all v0.37 data, transformation, analytics, visualization, statistics, engineering, ML, AutoML, API, monitoring, scheduling, governance, observability, and rollback capabilities.

New architecture features:

- canonical project-state defaults;
- v0.36/v0.37-to-v0.38 migration;
- structural project validation;
- migration history;
- structured diagnostic events;
- diagnostic JSONL files for headless runs;
- Diagnostics Center in the desktop app;
- shared schedule and dependency policy;
- shared retry execution;
- background tasks with progress and cooperative cancellation;
- thirteen automated core and architecture tests.
