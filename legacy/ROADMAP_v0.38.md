# Data Studio Roadmap after v0.38

## v0.39 — Trusted Project and Model Packages
- Add ZIP/JSON/Parquet project storage with a versioned manifest.
- Add checksums, optional signatures, schema validation, and migration from trusted legacy pickle projects.
- Add safer model packages with provenance and dependency metadata.

## v0.40 — Operations and Evidence Center
- Add searchable logs, correlation views, retention policies, environment comparisons, release timelines, and deployment trend charts.
- Add configurable health policies and richer rollback playbooks.

## v0.41 — UX and Accessibility
- Replace dense modal flows with durable task pages.
- Add progress/cancellation UI using the v0.38 task manager.
- Add keyboard, screen-reader, contrast, and theme validation.

## v0.42 — Extensibility
- Add a documented plugin model for sources, transformations, models, validators, charts, and deployment targets.
- Add plugin isolation and compatibility checks.
