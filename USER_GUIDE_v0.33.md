# PBX Data Eng v0.33 User Guide

## Contract tests
Open Ctrl+K, choose Contract test automation, create a suite from the active dataset contract, and run it. ERROR and FAIL findings block the test by default. Export the latest run as JSON when evidence is needed for CI/CD or audit review.

## Lineage export
Open Ctrl+K, choose Export lineage, then select PNG or SVG. Use PNG for email, Word and dashboards. Use SVG for presentations, architecture documentation and lossless scaling.
