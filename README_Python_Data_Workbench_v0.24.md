# Python Data Workbench v0.24 - Workspace Personalization

- Existing Ctrl+K Quick Actions, Getting Started, Workspace Overview and Recent Actions retained.
- The complete analytics, SQL, ML, monitoring, REST, scheduler and headless automation capabilities remain retained.
